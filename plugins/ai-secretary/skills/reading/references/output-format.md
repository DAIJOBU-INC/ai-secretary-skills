# 読書ガイド 出力フォーマット

`/reading` の Phase 4（出力生成）で使う雛形。ここを読んでから書き始める。

## 雛形

```markdown
# [書名] — [著者]

**あなたの仕事のための読書ガイド**


## 1. なぜ今この本なのか

[ユーザーが語った「きっかけ・壁」と、この本が応える問いを接続する]

**いまの優先事項との接続:**

- **[優先事項1に直撃する。]** [具体的な接続の説明]
- **[優先事項2にも効く。]** [具体的な接続の説明]


## 2. この本の核心（3行で）

[著者が最も伝えたいことを3行に凝縮する]
[章ごとの羅列ではなく、本全体を貫くメッセージ]


## 3. 本の地図 — 読み方ナビ

全[X]章の構成:

### [章番号]　[章タイトル]
- **重要度:** ★ 最優先 / 余裕があれば / 飛ばしてもOK
- **理由:** [なぜこの優先度か — ユーザーの課題との関連で説明]

### 推奨読書ルート（最短版 — 急ぎなら[N]章構成）

> **[章番号] → [章番号] → [章番号]**

[この順番で読む理由の説明]


## 4. 重要コンセプト（概要レベル・ネタバレなし）

本書のコアとなる概念を、章の順番ではなくテーマ別に整理する。
3〜5個のコンセプトを記載。

### [コンセプト名]

- **本の主張:** [著者が言っていること]

- **裏を返すと:** [この主張の前提・限界・反論。鵜呑みにしない視点]

- **あなたの仕事では:** [この概念があなたの状況にどう当てはまるか。具体的な人物（仮名でも可）・場面を使って書く]


## 5. 自分に問いかける — 内省ワーク

この本の内容を踏まえて、あなた自身に問いかける質問。
移動時間や朝の時間に頭の中で転がすための問い。
5〜7個。抽象的すぎず、あなたの状況に即した文脈を含む。

**問い1**「[問いの内容]」
> [背景: なぜこの問いが重要か。本のどの概念に基づくか]

**問い2**「[問いの内容]」
> [背景: ...]


## 6. 明日から使えるアクション

「やろうと思えば明日できる」粒度に絞った3〜5個の行動。

**アクション1　[アクション名]**
- 何をする: [具体的な行動。曖昧さゼロ]
- いつ: [今週 / 次の1on1 / 今月中]
- 誰と: [対象メンバーや取引先]
- 本との接続: [どの概念から導かれたか]


## 7. この本を一言で持ち歩く

> 「[この本から得た最も重要な一文]」

[日常で想起できる、自分のものとして持ち歩けるフレーズ]
```

## 重心調整ルール

Phase 2 のヒアリング（これから読む／読了済み／途中）に応じて厚みを変える。

| 状況 | 厚くするセクション | 薄くする・省くセクション |
|---|---|---|
| これから読む | 3（本の地図） | 4はネタバレしない概要レベルに留める |
| 読了済み | 5（内省ワーク）・6（アクション） | 3は省略可 |
| 途中 | 読んだ範囲の4 ＋ 未読章の3 | — |

## 品質基準（ここを外すと価値が出ない）

- **「あなたの仕事では」が汎用記述になっていないか。** 具体的な人物（仮名でもよい）・場面が入っていること。良い例: あるガイドでは、心理学的な原則を「メンバーの自走を促す場面」「商談のクロージング」「採用オファーの出し方」など複数の具体的な場面に紐付けた
- **アクションが「いい感じにやってみよう」になっていないか。** 「月曜の1on1で○○について問いかける」レベルの具体性が要る
- **内省ワークが「あなたはどう思いますか？」になっていないか。** あなたの状況に踏み込んだ問いにする
- **「裏を返すと」を省いていないか。** 本を批判するためではなく、盲目的に適用しないための視点
