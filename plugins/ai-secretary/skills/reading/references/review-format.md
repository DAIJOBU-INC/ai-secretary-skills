# 振り返り・再読フォーマット

`/reading [書名] --review`（Phase 6）と、同じ本を読み直すときに使う雛形。
どちらも**既存のガイドファイルに追記する**。新しいファイルは作らない。

## 1. 実践の振り返り（--review）

読書ガイド保存から2週間後を目安に実行する。セクション6のアクションを1件ずつ「やった？どうだった？」と確認し、以下を末尾に追記する。

```markdown
## 8. 実践の振り返り（YYYY-MM-DD）

| アクション | 実施 | 結果・学び |
|---|---|---|
| [アクション1] | done / skip / 変更 | [何が起きたか] |

### 次に試すこと
- [振り返りから生まれた新しいアクション]

### この本から残った一番の学び
> [実践を通じて腹落ちしたこと]
```

### 振り返りのときの姿勢

- **skip を悪いことにしない。** 状況が変わって不要になったなら、それ自体が学び。「なぜ skip したか」を1行残す
- **「変更」を歓迎する。** 本の通りにやらず自分流に変えたなら、その差分が一番価値がある
- 実施率が低いときは、アクションの粒度が粗すぎた可能性を疑う。次のガイドで具体性を上げる材料にする

## 2. 再読（同じ本を違うレンズで読む）

このスキルの一番リッチな使い方。同じ本でも、そのとき抱えている課題が変われば読める中身が変わる。

**ルール: 1冊1ファイル。既存のガイドに追記する。**

同じ本を読み直すたびに別ファイルを作ると、関心の移り変わりが追えなくなる。1冊のファイルを時系列で追えば「あるときは個人スキルの視点で読み、別のときは組織づくりの視点で読んだ」という変化が1枚で見える。

追記フォーマット:

```markdown
---

# 再読（YYYY-MM-DD）— レンズ: [今回の読みの焦点]

**なぜ再読するか:** [今ぶつかっている壁。前回とどう変わったか]

## 前回から変わったこと

[前回のガイドを読み返して、いま違って見える点。前回のアクションのその後]

## 今回のレンズで読み直したコンセプト

### [コンセプト名]
- **今回の読み:** [同じ記述がいま何に見えるか]
- **あなたの仕事では:** [いまの状況への当てはめ]

## 今回のアクション

**アクション1　[アクション名]**
- 何をする / いつ / 誰と / 本との接続

## 今回の一言

> 「[今回持ち帰るフレーズ]」
```

レンズの例: 組織・チーム作り / 採用 / 営業クロージング / 自分の意思決定の癖 / 事業への応用

## 3. 保存先

| 対象 | パス |
|---|---|
| 現行のガイド | `work/reading/YYYYMMDD_読書_[書名短縮].md` |
| リサーチ成果物 | `work/reading/research/YYYYMMDD_research_[書名].md` |

`--review` や再読でファイルを探すときは `work/reading/` を見る。別途アーカイブ運用がある場合はそちらも確認する。
