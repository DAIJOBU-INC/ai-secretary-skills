# メンバーファイルの雛形

`context/members/<名前>.md` がまだ無いメンバーの1on1を書き戻すときは、この形で新規作成してから追記する。

```markdown
---
updated: YYYY-MM-DD
---

# <氏名>（<よみがな>）

役割: <役割・担当>

## プロフィール

| 項目 | 内容 |
|---|---|
| 氏名 | |
| メール | |
| 役割 | |
| 入社（参画）時期 | |
| 強み | |
| 伸びしろ | |

## 目標・ゴール

| 期間 | 目標 |
|---|---|
| 短期（〜3ヶ月） | |
| 中期（〜1年） | |
| 長期（3年〜） | |

## 評価トラッキング

評価や到達度を記録したい場合に使う（空欄のままでよい）。

| 時期 | 項目 | 状態・評価 | 根拠（1on1の日付など） |
|---|---|---|---|

## 成長ロードマップ

次に伸ばしたい力と、そのための機会（任せる仕事・学ぶこと）を書く。キャリアの選択肢は1本に絞らず、複数のルートを並べてよい。

## 週次最優先タスク記録（時系列）

週次1on1の定型2問（今週やった1番大事なこと／来週やる1番大事なこと）を時系列で蓄積する。最新が上。

| 週 | Q1. 今週やった1番大事なこと | Q2. 来週やる1番大事なこと | コメント |
|---|---|---|---|

## 1on1ログ（時系列）

最新が上。1件ずつ `### YYYY-MM-DD（1on1）` の見出しで追記する。

## メモ・気づき

新しい気づき、印象的な発言、成長の兆候を日付つきで書く。
```

## 書き方の注意

- 「1on1ログ」「週次最優先タスク記録」の見出し文言は `1on1-writeback` スキルが検索する目印なので変えない
- プロフィール表は分かっている項目だけ埋め、不明な項目は空欄のままでよい
- 「目標・ゴール」「評価トラッキング」「成長ロードマップ」は `mtg-prep` が1on1の準備で読み込む。最初は空欄でよく、1on1を重ねながら埋めていく（`1on1-writeback` は、中身があるセクションを更新対象として扱う）
- 個人情報（電話番号・住所等）を含めることになった場合は、その情報だけ別ファイルに分けるか、リポジトリの除外設定に入れることを検討する
