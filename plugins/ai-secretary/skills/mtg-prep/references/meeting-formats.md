# 通常/キックオフMTG: 出力フォーマットと外部出力

通常MTG・キックオフMTGの出力構成をまとめる。Webリサーチは全MTGタイプ共通。

## Webリサーチ（全MTGタイプ共通）

手順4の情報収集と合わせて、Webリサーチも行う（重ければ別タスクに分けてもよい）。

### 検索内容

- 相手企業の最新ニュース・プレスリリース（直近3ヶ月）
- 相手の業界動向・トレンド
- 相手企業の決算・IR情報（上場企業の場合）
- 競合他社の動き（相手の業界内での位置づけ把握）

### 検索クエリの組み立て方

1. 企業名＋「ニュース」「プレスリリース」で最新動向
2. 業界名＋「動向」「トレンド」で業界情報
3. 企業名＋自社の提案テーマに関連するキーワード（例:「DX」「業務効率化」「新規事業」）

### 出力への反映

- 顧客共有セクション: 「貴社の最近の取り組みについて」として公開情報ベースで言及（商談の話題づくり）
- 社内メモセクション: 業界動向・競合情報・提案に活かせるポイントを整理

### 注意事項

- 公開情報のみ使用（機密情報は含めない）
- 情報ソース（URL）を社内メモセクションに記載
- 検索で有用な情報が見つからない場合は無理に含めない

## 通常MTG出力構成

【顧客共有セクション】
基本情報（日時/参加者/リンク）→ 前回のお打ち合わせ概要（事実ベース）→ 貴社の最近の取り組みについて（公開情報ベース、話題づくり）→ 本日のアジェンダ案（**冒頭に先回り提案1本・必須**。SKILL.md「先回り提案」参照）→ ご確認事項 → メモ欄

【社内メモセクション】
前回MTGの率直な振り返り → 営業戦略メモ → **先回り提案の裏側（狙い・想定反論・価格感／出せなかった場合は理由）** → 相手・業界リサーチ（最新ニュース・業界動向・提案ポイント・情報ソースURL）→ 関連する社内の動き（チャット/メール要約）→ 人物メモ → 関連資料一覧（社内パス含む）→ 事前準備チェックリスト → **調べた範囲の表（必須・SKILL.md参照）**

## キックオフMTG出力構成

【顧客共有セクション】
基本情報 → プロジェクト概要（サービス/体制/期間）→ キーステークホルダー → アジェンダ案（自己紹介→スコープ確認→体制合意→スケジュール→環境整備→進め方の確認）→ **先回り提案1本（必須・SKILL.md参照）** → メモ欄

【社内メモセクション】
契約条件の詳細（金額等）→ スコープ詳細 → 相手・業界リサーチ（最新ニュース・業界動向・競合情報・提案ポイント・情報ソースURL）→ リスク・制約（社内視点）→ 営業戦略・拡大方針 → **先回り提案の裏側（狙い・想定反論・価格感／出せなかった場合は理由）** → 人物メモ → 関連資料一覧（社内パス含む）→ 事前準備チェックリスト → **調べた範囲の表（必須・SKILL.md参照）**

## 他形式での出力（任意）

Markdownで保存した後、Word や Google ドキュメントの形にしたい場合は、使える変換スキル・ツール（docx変換、Google Docs変換等）があればそれを使う。
顧客に共有する場合は、変換後に社内メモセクション以降を手動で削除してから共有するよう案内する。
