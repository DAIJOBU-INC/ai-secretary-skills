# 1on1専用フロー: 情報収集と出力構成

MTGタイプ判定で1on1と判定された場合、以下のフローに従う。
通常MTGの2部構成（顧客共有/社内メモ）は使わず、1on1専用の出力構成で生成する。

## メンバー情報の解決

1. `context/members/` 配下のファイルを検索し、該当メンバーの成長追跡ファイル（メンバーファイル）を読み込む
2. ファイルが存在しない場合:
   - **本人から直接頼まれたとき**（対話実行）→ 「◯◯さんの記録（メンバーファイル）がまだありません。先に作りますか？」と確認する。作る場合は 1on1-writeback（このパック）の雛形で作り、分かっている項目だけ埋めてから進む。作らない場合は、末尾の「メンバーファイルが存在しない場合のフォールバック」の短縮版にする
   - **定期実行（無人）のとき、または daily-schedule など他のスキルから呼ばれたとき** → 聞かずに短縮版にする
3. 読み込む情報: プロフィール / 目標・ゴール（短期・中期・長期）/ 評価トラッキング / 成長ロードマップ / 過去の1on1ログ / メモ・気づき / （あれば）タスク管理・評価ツールの連携ID

## 1on1データ収集（並列実行）

以下を並列で取得する:

1. **チャット**: メンバー名で検索 → 直近7日の投稿・やり取りを抽出（業務報告・質問・共有・日報）
2. **議事録ツール**: メンバー名でミーティング検索 → 直近2週間のMTG一覧・AI要約・決定事項・アクションアイテム
3. **カレンダー**: メンバー名で今後2週間の予定 → 顧客MTG・社内MTG・研修等
4. **タスク管理・評価ツール**: メンバーの連携IDから評価ページを取得（存在する場合）
5. **前回1on1の情報**: 成長追跡ファイルの1on1ログから前回の内容を抽出 + 議事録ツールで前回1on1のAI要約
6. **前回の申し送り**: 成長追跡ファイルの直近1on1ログに「次回への申し送り」があれば読み込み、アジェンダ案に優先反映する

## 材料が何も無いとき（作る前に確かめる）

メンバーファイルが無く（または作ったばかりで記録が無く）、チャット・議事録ツールもつながっておらず、メモの貼り付けも無いときは、書ける中身が定型の質問・事前メッセージ案・時間配分しか残らない。空欄ばかりの資料を黙って作らない。この場合は上の「先に作りますか？」を聞かず、次の確認だけにする（質問を2つ続けない）。

- **対話実行時**: 作る前に、いま作れる範囲を伝えて選んでもらう。例:「◯◯さんの記録がまだ無く、チャットと議事録の道具もつながっていません。①最近の様子（メモややり取り）を貼ってもらって作る ②定型の質問・事前メッセージ案・時間配分だけで作る ③今回は作らない、のどれにしますか？」。①なら貼ってもらった内容を材料に、②ならそのまま、末尾のフォールバックの短縮版で作る。本人がすでに「それでも作る」と答えているとき（daily-schedule が先に聞いた場合など）は、聞き直さずに②で作る
- **定期実行（無人）時**: 作らない。「材料が無いため未作成」と呼び出し元に返す（daily-schedule は工程表の「要確認」に書く）

## 1on1出力構成

### 1. メンバーサマリー

- 氏名 / 役割 / 現在のフェーズ（成長ロードマップのどこか）
- 強み / 伸びしろ（成長追跡ファイルから）

### 2. 前回1on1の振り返り

- 前回の日付・議題
- 決定事項・アクションアイテムの進捗（チャット・議事録ツールで裏取り）
- 未完了のアクションアイテムがあれば強調

### 3. 直近の活動ハイライト

- チャットでの発言・貢献（日報提出状況、業務報告、質問・相談）
- 参加したMTG一覧と要約
- 注目すべき行動（褒めるべきポイント）
- 気になる点（遅延・未対応・コミュニケーション減少等）

### 4. 成長目標チェックイン

- 現在のフェーズと卒業基準
- 短期目標の各KPIに対する進捗（わかる範囲で）
- 行動指標の実行状況（日報提出率、対応速度等）
- 前回評価からの変化

### 5. 週次定型質問（必須・週次1on1）

週次1on1では**毎回必ず**以下2問を聞く。メンバーの優先順位を言語化させ、フォーカスを定着させる。

**Q1. 今週やった1番大事なことは何だった？**

- 成果・アクション・決断など形式は問わない。本人が「今週これだった」と言えるものを引き出す
- 複数挙げそうなら「1つに絞るなら？」で絞らせる

**Q2. 来週やる1番大事なことは？**

- 意志（やるつもり）を言語化させる。数・期限は言えるなら言う
- 曖昧なら「具体的に何をする？」「いつまでに？」で深掘り

**運用ルール**:

- **事前メッセージ案にも必ず含める**（「今週の1番大事なこと／来週の1番大事なことを考えておいてね」の1行）
- タイムボックスでは**チェックイン直後に2-3分**を確保（テンプレートA）
- 回答は次回以降の1on1準備の材料になるので、メンバーファイルの記録に蓄積しておく（手動転記、または自動化があれば任せる）
- 月次1on1（テンプレートB）は「この1ヶ月 / 来月の1番大事なこと」に読み替えて運用推奨

### 6. 事前メッセージ案

1on1の**前日夕方**にメンバーへ送るメッセージ案を生成する（当日朝だと準備時間が足りないため）。

メッセージの冒頭に前回の振り返り1行を添える:
例: 「前回は［来期の目標の立て方］について話したよね。あの後どうなったかも含めて〜」

**週次1on1の事前メッセージには必ず以下を含める**:

> 「明日の1on1で、今週やった1番大事なこと／来週やる1番大事なことをそれぞれ聞くから、考えておいてね」

成長フェーズに応じてテーマ設定方法を変える:

- Phase 1（型の確立期）: 6カテゴリから1つ選ぶ形式
- Phase 2以降（自走期）: 「今日話したいこと、自分で決めて持ってきて」に移行

6カテゴリ（Phase 1向け）:

1. 仕事の状況 — 進捗・詰まってること・判断に迷っていること
2. コンディション — 負荷感・モチベーション・休めているか
3. 成長・キャリア — やりたいこと・伸ばしたいスキル・将来の不安
4. 関係・フィードバック — 上司への要望・チームへの不満・もらいたいサポート
5. 組織・会社への疑問 — 方針への違和感・評価へのモヤモヤ・言いにくかったこと
6. プライベート・ライフ — 仕事に影響している体調や生活・最近しんどいこと

### 7. タイムボックス（時間配分ガイド）

メンバーの1on1頻度と成長フェーズに応じて、以下のテンプレートを自動選択して記載する。

**テンプレートA: 週次30分**

| 時間 | パート | 内容 |
| --- | --- | --- |
| 0:00-2:00 | チェックイン | 「今日のコンディション、10点満点で何点？」5点以下ならコンディションの話に全振り |
| 2:00-5:00 | **週次定型質問（必須）** | **Q1. 今週やった1番大事なことは？ / Q2. 来週やる1番大事なことは？** 各60-90秒で答えさせる。深掘りはクロージングで |
| 5:00-8:00 | 前回アクション確認 | 済/未済を淡々と確認。深掘りしない（詳細はチャット/日報で済んでいる） |
| 8:00-16:00 | メンバーのターン | 事前カテゴリの話を聞く。上司は聞くだけ。沈黙OK |
| 16:00-26:00 | 深掘りと気づき | 第2層・第3層の問いで対話。フィードバックもここで（上司の発言は3割以内） |
| 26:00-30:00 | クロージング | 本人にアクションを宣言させる。最大3つ。「来週やる1番大事なこと」を改めて確認 |

**テンプレートB: 月次60分**

| 時間 | パート | 内容 |
| --- | --- | --- |
| 0:00-3:00 | チェックイン | 「この1ヶ月、10点満点で何点だった？」（四半期初回回は**「次の3ヶ月で何ができたら最高？」**を冒頭に差し込む） |
| 3:00-6:00 | **月次定型質問（推奨）** | **Q1. この1ヶ月やった1番大事なことは？ / Q2. 来月やる1番大事なことは？** 各90秒で |
| 6:00-10:00 | 前回アクション・KPI確認 | 数値でざっと確認。深掘りしない |
| 10:00-25:00 | メンバーのターン+深掘り | 感情・気づき・葛藤を引き出す。第2層の問い中心 |
| 25:00-40:00 | 成長設計 | Phase移行・自己認識・未来志向の問い。上司のフィードバックもここで |
| 40:00-50:00 | 組織・チームの話 | 月次だからできる大きな話題。方向性への率直な意見を聞く |
| 50:00-60:00 | クロージング | 来月のフォーカス1つ + アクション3つ以内。「来月やる1番大事なこと」を改めて確認 |

**テンプレートC: 初回60分**（新メンバー/目標未設定の場合）

| 時間 | パート | 内容 |
| --- | --- | --- |
| 0:00-5:00 | 自己紹介・アイスブレイク | 心理的安全性の構築が最優先 |
| 5:00-20:00 | 現在地の確認 | 今の仕事の状況・手応え・困りごと。第2層の問いで深掘り |
| 20:00-35:00 | ミッション・目標の合意 | 「どうなりたいか」を本人に語ってもらう。第4層の問い中心 |
| 35:00-50:00 | 成長ロードマップの説明 | Phase制の説明。短期目標KPIの合意 |
| 50:00-60:00 | 1on1の進め方の合意 | 頻度・事前メッセージ・カテゴリの説明 |

### 8. 今回の1on1アジェンダ案

質問候補（4層の問い・四半期質問・対話技法）は `references/1on1-questions.md`、設計理論は `references/1on1-principles.md` に分離している（SKILL.mdが必要時にそれらを案内する）。本セクションはアジェンダの組み立て構造のみを示す。

前回の申し送りがあればアジェンダ冒頭に反映する（「前回の振り返りで○○が課題だったので今回は△△を意識する」等）。

- 必ず話すべきこと（未完了アクション、前回の宿題）
- 話した方がいいこと（成長機会、改善フィードバック）
- 褒めるポイント（具体的な行動を引用）
- 耳の痛いフィードバック（言いにくいが伝えるべきこと。具体的な事実ベースで）

### 9. 今後2週間のカレンダー

- メンバーの予定一覧（顧客MTG・社内MTG等）

### 資料の末尾: 調べた範囲の表

9のあとに、SKILL.md の「調べた範囲の表」を入れる。行は、チャット・議事録ツール・カレンダー・タスク管理／評価ツール・メンバーファイル（前回の1on1ログと申し送りを含む）の5つにする（貼ってもらったメモを使ったときは、その行を足す）。

セクション2・3・9のうち、道具がつながっていない・記録が見つからないために書けないものは見出しごと省き、省いたことをこの表の該当する行の結果列に書く（例: チャットの行に「—（『直近の活動ハイライト』は省いた）」）。各セクションに「取得できず」と並べない。省いたセクションがあるときは、資料の見出しの番号を詰めて振り直す。

## 1on1出力先

`work/mtg/YYYYMMDD_1on1_[メンバー名].md` に保存する。

## 1on1の注意事項

- 成長追跡ファイルの「メモ・気づき」セクションは特に重要。過去の観察を踏まえた準備にする
- 数値で語れることは数値で（日報提出率、商談設定数等）
- メンバーの報告を聞くときは**事実か解釈かを切り分ける**（「好感触です」「前向きに検討中です」は解釈）。曖昧なまま「で、どうしたいの？」と返さない。切り分けの問いと「事実→解釈→アクション」の3層フォーマットは `references/1on1-questions.md` 参照

## メンバーファイルが存在しない場合のフォールバック

メンバーファイルが存在しないメンバーの場合、チャット・議事録ツール・カレンダー（と、貼ってもらったメモ）からの情報だけで以下の短縮版を作る。セクション番号は上の「1on1出力構成」の1〜9と同じ。メンバーファイルが無くても作れる5〜7は、短縮版にも入れる。

- セクション1（メンバーサマリー）: 氏名・役割のみ（強み/伸びしろは省略）
- セクション2（前回1on1の振り返り）: 議事録ツールか、貼ってもらったメモに前回の記録が見つかれば記載
- セクション3（直近の活動ハイライト）: チャット・議事録ツール（と、貼ってもらったメモ）から通常通り作成
- セクション4（成長目標チェックイン）: 中身は省略し、見出しの下に「成長追跡ファイル未作成のため省略」と1行書く
- セクション5（週次定型質問）: 通常通り入れる
- セクション6（事前メッセージ案）: 入れる。冒頭の「前回の振り返り1行」は、前回の記録が見つかったときだけ添える。成長フェーズが分からないので、テーマ設定は Phase 1（6カテゴリから1つ選ぶ形式）にする
- セクション7（タイムボックス）: 入れる。頻度と成長フェーズが分からないので、予定の長さで選ぶ（30分前後ならテンプレートA、60分前後ならテンプレートB。60分前後で、はじめての1on1だと分かっていればテンプレートC）。予定の長さも分からなければテンプレートAにし、仮置きであることを書く
- セクション8（今回の1on1アジェンダ案）: 通常通り作成 + 上司自身の確認事項として「成長追跡ファイルを作成するか決める（1on1のあとに 1on1-writeback で記録すると作られる）」を1行足す
- セクション9（今後2週間のカレンダー）: 通常通り作成

セクション2・3・9のうち、材料が無くて書けないものの扱いは、通常の資料と同じ（上の「資料の末尾: 調べた範囲の表」のとおり、見出しごと省いて表に書く）。
