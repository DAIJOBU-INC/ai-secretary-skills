# 1on1質問カタログと対話技法

1on1のアジェンダに入れる質問候補と、質問以外で考えさせる技法をまとめる。

## 4層の問い（質問候補）

メンバーの成長フェーズに応じて各層の配分を調整する:

- Phase 1（型の確立）: 第1層10% / 第2層40% / 第3層30% / 第4層20%
- Phase 1→2（自走移行）: 第1層5% / 第2層25% / 第3層40% / 第4層30%
- 目標設定期（初回〜数回目）: 第2層30% / 第3層30% / 第4層40%

各層から2-3問ずつ、計8-10問を生成する。同じ質問を繰り返さないよう、毎回異なる組み合わせを選ぶ:

**第1層: 事実確認**（最小限に抑える。5分以内に終わらせる）

- 「前回のアクション、どこまで進んだ？」（一問で済ませる）
- 「前回から何か大きく変わったことはあった？」

**第2層: 意味づけ — 経験学習サイクル**（体験の「なぜ」を本人に言語化させる）

経験の振り返り:

- 「それをやってみて、自分の中で何か変わった？」
- 「一番手応えがあったのはどの瞬間？逆に、嫌だなと思った瞬間は？」
- 「思ったより簡単だったこと、思ったより難しかったことは？」
- 「もう1回やるなら、何を変える？」
- 「成功した要因は何だと思う？」（ヤフーの1on1: 経験学習）
- 「うまくいった時と今回との違いは何だと思う？」（ヤフーの1on1）
- 「この1週間で一番印象に残ってる場面は？なぜそれが印象に残った？」

深掘り（チャンクダウン/アップ）:

- 「具体的にはどういうこと？」（チャンクダウン: 抽象→具体）
- 「もう少し詳しく聞かせて」（ヤフーの1on1）
- 「つまりそれは、どういうことだと思う？」（チャンクアップ: 具体→法則化）
- 「このできごとから、何を学んだ？」（ヤフーの1on1: 概念化）
- 「次に同じ状況になったら、どうする？」（経験学習: 新しい状況への適用）

事実と解釈を分ける（報告が曖昧なとき・「好感触です」的な答えが返ってきたとき）:

- 「それは事実？それとも解釈？ 誰が、いつ、何と言った？」
- 「『好感触』って、具体的に誰のどの発言から？」
- 「いま話してくれたのは解釈だね。その元になった事実を3つ挙げてみて」
- 「その事実からその解釈になった理由は？ 他の解釈もありえる？」
- 「じゃあ、その解釈で動くとしたら次のアクションは何になる？」（3層に着地させる）

> 混ざりやすい表現の見分け方: 「好感触です」→誰のどの発言か／「前向きに検討中です」→期限と決裁者は誰か／「価格がネックです」→そう言ったのか推測か／「時期が悪いだけです」→比較対象は何か

感情・モチベーション:

- 「最近の仕事で、楽しいと感じる瞬間はどこ？」（世古詞一: モチベーション）
- 「今週、仕事が前に進んだ実感があったのはどの場面？」（アマビール: 進捗の法則）
- 「逆に、進捗を妨げてるものって何？」（アマビール: 進捗の法則）

**第3層: 自己認識**（自分のパターン・強み・弱みへの気づき）

自己評価:

- 「3ヶ月前の自分と比べて、一番変わったと思うところは？」
- 「今の自分の仕事ぶりに点数をつけるなら？その点数の理由は？」
- 「Phase 1の卒業基準、正直いまどのくらいの距離感？」
- 「自分の強みって何だと思う？最近それを活かせた場面はあった？」
- 「チームの中で自分がいないと困ることって何だと思う？」

本質に切り込む:

- 「あなたにとって、いま本当の課題は何だと思う？」（The Coaching Habit: Focus Question）
- 「あなたは何を望んでいる？」（The Coaching Habit: Foundation Question）
- 「根源的な問題って何だと思う？」（ヤフーの1on1）
- 「その行動は、周りからどう見えてると思う？」（フィードバック入門: 鏡の役割）

パターン認識:

- 「最近繰り返してしまっていることはある？」
- 「自分が避けがちなことって何だと思う？」
- 「得意だと思ってることで、実は盲点になってるものってあると思う？」

**第4層: 未来志向 — GROWモデル応用**（本人に「次に何をすべきか」を考えさせる）

目標・ビジョン（Goal）:

- 「**次の3ヶ月で何ができたら最高？**」（四半期アンカー質問。月初/四半期初回はオープニングで必ず聞く）
- 「半年後にどういう自分になっていたい？そのために今月やるべきことは？」
- 「理想の状態って、どんな姿？」（GROWモデル）
- 「その目標が達成できたら、どんな気持ちだと思う？」（GROWモデル）

選択肢・戦略（Options）:

- 「他にどんな方法がありそう？」（GROWモデル）
- 「もし制約が一切なかったら、何をする？」（GROWモデル）
- 「尊敬する人だったら、どうすると思う？」（GROWモデル）
- 「これにYesと言うなら、何にNoと言うことになる？」（The Coaching Habit: Strategic Question）
- 「もし自分が自分のマネージャーだったら、今の自分に何を言う？」

行動計画（Will）:

- 「次の1週間で、1つだけ変えるとしたら何を変える？」
- 「来週の1on1で『これができた』と言いたいことは？」
- 「やり通す確率、10段階でいくつ？ その評価を10にするには何が必要？」（GROWモデル）
- 「最初の一歩として、何をする？」（GROWモデル）
- 「俺にできることは何かある？」（The Coaching Habit: Lazy Question）

**ブリッジ質問**（業務の話が長くなったとき、「人の話」に転換する。必ず1つ含める）

- 「なるほど。その仕事してるとき、正直どんな気持ち？」
- 「それって前もあった？自分のパターンだと思う？」
- 「その件で一番学んだことは何？」
- 「仕事の話は分かった。ところで、最近コンディションはどう？」
- 「他には？」（The Coaching Habit: AWE Question — 最も万能な深掘り質問）
- 「今の話を一言でまとめると、何だと思う？」（パラフレーズ促し）

**締めの質問**（クロージングで必ず1つ使う）

- 「今日の話で、一番役に立ったことは何だった？」（The Coaching Habit: Learning Question）
- 「今日決めたアクションを確認しよう」
- 「サポートが必要なことはある？」（GROWモデル）

**フィードバックの構造**（褒める時も指摘する時もこのフレームで）

- SBIモデル（中原淳『フィードバック入門』）:
  S = Situation（いつ・どこで）→ B = Behavior（何をしたか）→ I = Impact（その結果どうなったか）
- 褒める例: 「先日の訪問で（S）、自分から足を運んで話を進めてくれたよね（B）。あの行動力があると、周りのメンバーにも良い影響がある（I）」
- 指摘する例: 「今週の経費精算で（S）、相手から4回催促が来てた（B）。管理側の負担が増えるし、信頼面でも気になる（I）。どうすれば改善できると思う？」
- フィードバック後: 「どう思う？同意できる？」（Radical Candor）で相手の受け止めを確認する

NG質問を避ける: 「**最近どう？**」「うまくいってる？」「なんかある？」「困ってることない？」→ 「はい」で終わる、または雑談に流れる
- 「最近どう？」の代替: 業務確認は週次定型質問（Q1/Q2）で済ませ、雰囲気の話は「今日のコンディション10点満点で？」（チェックイン）で済ませる。本人の視座を引き上げたいときは下記の四半期質問を使う。
- 「**で、どうしたいの？**」「どうすればいいと思う？」も同じNG。**前提を共有しないまま投げると丸投げになる**。相手は「どうしたいか」ではなく「どういう状況か分からない」状態で、答えなければ主体性がないと誤評価され、答えれば的を外す。ある企業のマネジャー研修で採点させると平均50点／100点という調査結果がある。低評価の理由は「上司が責任を放棄していると感じた」
  - 代替: 「**今わかっている事実を3つ挙げて。それから、あなたの解釈を聞かせて**」（中田豊一: 聞きたいことを絞り込むと相手は答えやすくなる）
  - 判定基準: この質問を投げる前に「自分は前提を共有したか？」を自問する。共有していないなら丸投げ。丸投げは配慮ではなく放棄
  - 出典: マネジャー研修における「おまえはどうしたい」問題の分析（安斎勇樹氏）

## 四半期質問（3ヶ月に1回、月初の1on1の冒頭に必ず聞く）

「**次の3ヶ月で何ができたら最高？**」

- 「最近どう？」を恒常的に置き換えるアンカー質問。視座を「直近の業務」から「3ヶ月先の理想」に持ち上げる
- 月次/隔週1on1なら **四半期初回（1月・4月・7月・10月）** のオープニングで必ず1問目に使う
- 週次1on1でも **3ヶ月に1回** はチェックイン直後に差し込む（その回は週次Q1/Q2の前に置く）
- 回答が出たら「そのために来週/来月の1番大事なことは何？」で週次/月次の定型質問につなぐ
- 出典: Keisuke Nishitani氏（@Keisuke69）の投稿

## 報告の型「事実 → 解釈 → アクション」（メンバーに渡す3層フォーマット）

1on1で報告が曖昧なとき、質問で掘るだけでなく**型そのものを渡す**。特に Phase 1（型の確立）のメンバーには、判断軸を教える前にこの器を固定するほうが早い。

1. **事実**を並べる（誰が・いつ・何と言ったか。解釈を混ぜない）
2. **自分の解釈**を示す（事実からどう読んだか）
3. **次のアクション**を言い切る（宿題は自分が持ち、判断は上司に返す）

- 順番を変えない・混ぜない。最も崩れるのは第1層（事実のつもりが解釈になっている）
- 「どうしたいか」を聞かれているのではなく「**目線が揃っているか**」を確認されている、と本人に伝える
- 上司側の受け止め方: 答えを教えるのではなく、アクションの**承認**を返す（「その責任を取るために上司がいる」）
- 1on1での渡し方の例: 「次回から報告は事実3つ・解釈1つ・アクション1つの順で言い切ってみて。事実と解釈が混ざってたら都度止めるね」
- 信頼を失うNG返答3種（本人に伝える）: 「がんばります」／「じゃあ、どうしたらいいんですか？」／相手の言葉をそのまま運ぶだけの報告 — いずれも3層のどれか2つが欠けている
- 商談にも同型で使える（顧客の「あなただったら買いますか？」も前提のない丸投げ。逃げずに結論を言い切ってから残懸念に話を移す）
- 出典: マネジャー研修における「おまえはどうしたい」問題の分析（安斎勇樹氏）

## 対話テクニック（準備資料に毎回リマインドする）

質問以外で「考えさせる」技法:

- **「他には？」を3回使う**: 最初の答えが最良とは限らない。「他には？」で掘り続ける（The Coaching Habit: AWE Question）
- **パラフレーズ**: 相手の話を自分の言葉で言い換えて返す。「つまり、こういうこと？」→ 理解確認 + 相手が自分の考えを再認識する効果
- **ミラーリング**: 相手の言葉の一部をそのまま繰り返す。「〜〜なんだね」→ 「聴いてる」のシグナル
- **もう一つ質問する**: 相手が言い尽くしたと思ったタイミングで、あえてもう一問。ここに本音が出る（Andy Grove: HIGH OUTPUT MANAGEMENT）
- **承認（レコグニション）**: 行動・成果だけでなく「存在」を認める。「あなたがそう感じること自体が大事だよ」（ヤフーの1on1）
- **アドバイスしたい衝動を抑える**: "Stay curious a little longer, rush to action a little slower"（The Coaching Habit）。もう少し好奇心を持ち続け、行動を急ぐのを少し遅らせる

## 沈黙のルール（準備資料に毎回記載する）

- 質問した後、最低10秒は黙って待つ。すぐに助け舟を出さない
- 「うーん」と考えている時間はメンバーが成長している時間
- メンバーが「わからない」と言ったら →「わからないなりに、今思うことは？」と返す
- 上司が話し始めたくなったら、代わりに「他には？」と聞く
