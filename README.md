# AI秘書スキルパック

Claude Code を「自分専用のAI秘書」として使うためのスキル集です。
経営者・マネージャーが毎日くり返す仕事（会議の準備、議事録、1on1の記録、情報収集、発信）を、ひとことで頼めるようにします。

## 入っているスキル（8本）

| スキル | 何をしてくれるか | こう頼む |
|---|---|---|
| mtg-prep | 会議の前に、予定・過去の議事録・メール・チャット・手元のメモを集めて準備資料を作る。相手に見せてよい部分と社内メモの2部構成。1on1 の準備にも対応 | 「明日のA社との打ち合わせの準備資料をつくって」 |
| meeting-notes | 議事録を Slack／Teams／メールにそのまま貼れる文面にする（送信はしない） | 「さっきの打ち合わせの議事録を出して」 |
| 1on1-writeback | 1on1 の記録をメンバーごとのファイルに書き戻し、次の1on1につなげる | 「今日のAさんとの1on1を記録して」 |
| reading | 本の要点をつかみ、自分の仕事への実践ガイドにする。読んだ後の振り返りも | 「この本をまとめて」 |
| clip | 気になった記事・URLを要約して、タグ付きで保存する | 「これをクリップして」 |
| write-article | 自分の文体で、記事・発信文の下書きを書く（投稿は自分で） | 「このテーマで note の記事を書いて」 |
| eli5 | むずかしい仕組みを、大きな絵と少ない言葉の「しくみ絵本」で説明する | 「◯◯を絵本で説明して」 |
| downloads-triage | ダウンロードフォルダを週1回仕分ける（消さずに移動。動かす前に確認） | 「ダウンロードを整理して」 |

ふだんは上の「こう頼む」のような自然な言葉で頼めば、Claude が合うスキルを選びます。名前を指定して呼ぶときは `/ai-secretary:mtg-prep` のように書きます。

## 入れ方

### A. プラグインとして入れる（おすすめ）

Claude Code（デスクトップアプリの Code タブ、またはターミナル）で、次の2行を順に入力します。

```
/plugin marketplace add https://github.com/DAIJOBU-INC/ai-secretary-skills.git
/plugin install ai-secretary@daijobu
```

- **このリポジトリが非公開の場合**: 先に GitHub の招待を受け、GitHub にログインしておく必要があります。Claude Code に「GitHub にログインして、プラグインを HTTPS で取れるように設定して」と頼むと、`gh auth login` と `gh auth setup-git` を案内してくれます
- **更新を受け取る**: `/plugin` の画面（Marketplaces）で `daijobu` の自動更新をオンにしておくと、スキルが直されたときに自動で届きます。オフのままなら、同じ画面から手動で更新します

### B. フォルダをコピーして入れる

`plugins/ai-secretary/skills/` の中から使いたいスキルのフォルダを、自分のリポジトリの `.claude/skills/` にコピーします（例: `.claude/skills/mtg-prep/`）。この場合の呼び名は `/mtg-prep` です。自動の更新はありません。

## 前提のフォルダ構成

AI秘書ビルダーで作るフォルダ構成と同じです。無いフォルダはスキルが作ります。`CLAUDE.md` に別の保存先を書いておけば、そちらが優先されます。

```
CLAUDE.md
context/                 今の事実（上書きで育てる）
  owner/profile.md       自分のプロフィール・価値観・仕事の進め方
  company/overview.md    会社の概要・事業・用語
  clients/<相手先>.md     取引先ごとのカルテ
  members/<名前>.md       メンバーごとのファイル（1on1の記録など）
work/                    日々の成果物（追記で増える）
  mtg/  clips/  reading/  content/  daily/
```

`context/` に書いてあることが多いほど、スキルの出来が上がります。まずは `context/owner/profile.md` と `context/company/overview.md` から始めるのがおすすめです。

## つながっていると便利な道具

| 役割 | 例 | つながっていないとき |
|---|---|---|
| カレンダー | Google カレンダー／Outlook | 予定を貼って伝える |
| メール | Gmail／Outlook | 必要なメールを貼る |
| 議事録ツール | Circleback など | 文字起こしやメモを貼る |
| チャット | Slack／Teams | 必要なやり取りを貼る（LINE も貼れば使えます） |
| 資料置き場 | Google ドライブ／SharePoint・OneDrive | ファイルを手元に置く |

道具は Claude の「コネクタ」設定でつなげます。つながっていない道具について、スキルは黙って飛ばさず「使えなかった」と書くか、貼り付けをお願いしてきます。

## 安全のための約束（全スキル共通）

- **メールは下書きまで。** 送信・転送・予約送信はしません。送信ボタンは自分で押します
- **相手に見せる部分と社内メモを分けます。** 共有してよい部分に、金額・社内での評価・社内の段取りは書きません
- **パスワード・APIキーなどの認証情報は読まない・書かない**
- 人の特定は「メールアドレスが同じ」だけで決めつけず、迷ったら確認します

## 困ったとき

- スキルが呼ばれない → `/ai-secretary:スキル名` で直接呼ぶ。`/plugin` の画面で有効になっているか確認する
- 更新が届かない → `/plugin` の画面から `daijobu` を更新する

## メンテナンス（配る側向け）

- スキルを直したら、`plugins/ai-secretary/.claude-plugin/plugin.json` の `version` を上げます（上げないと利用者に更新が届きません）
- 変更したら `claude plugin validate .` で形式を確認します
- ここには一般化したものだけを置きます。社名・人名・金額・社内のIDは書きません
